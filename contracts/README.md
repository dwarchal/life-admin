# Umowy (contracts)

Jeden plik na umowę.

## Zasady wypowiadania ubezpieczeń w Szwajcarii (AXA)
- Umowa przedłuża się automatycznie o 1 rok, jeśli nie zostanie wypowiedziana najpóźniej 3 miesiące przed końcem.
- Od 2022 (rewizja VVG): forma tekstowa, np. e-mail, wystarcza; prawo wypowiedzenia na koniec 3. roku i każdego kolejnego roku dotyczy też starszych umów.
- Wypowiedzenie po szkodzie (Kündigung im Schadenfall): możliwe dodatkowo, według warunków ogólnych (AVB/GIC).

Szablon pól: dostawca, przedmiot umowy, data zawarcia, okres, automatyczne przedłużenie (tak/nie), okres wypowiedzenia, najwcześniejszy dzień wypowiedzenia, termin wypowiedzenia, forma wypowiedzenia (online / e-mail / list), koszt, link do skanu w Google Drive, notatki.
